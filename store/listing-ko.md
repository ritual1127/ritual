# Play 스토어 등록정보 (한국어)

Play Console > 성장 > 스토어 등록정보 > 기본 스토어 등록정보에 그대로 붙여 넣는다.

## 앱 이름 (30자 이내, 지금 20자)

```
성적계산기 - 수행평가·내신등급·학점
```

검색에 걸리는 핵심 말(성적계산기, 수행평가, 내신등급, 학점)을 이름에 넣었다. 아이콘 아래 이름은 앱 안 설정(`성적계산기`)이 쓰이므로 짧게 보인다.

## 간단한 설명 (80자 이내, 지금 45자)

```
점수만 넣으면 최종 점수와 등급이 바로! 목표 점수·내신 등급·학점·급식까지 무료
```

## 자세한 설명 (4000자 이내)

```
학교 성적, 계산기 두드리지 말고 점수만 넣으세요.
성적계산기는 수행평가·지필고사 반영 점수부터 남은 시험 목표 점수, 내신 석차등급, 대학 학점까지 한 번에 계산해 주는 무료 앱이에요. 회원가입 없이 바로 쓰고, 입력한 성적은 내 휴대폰에만 저장돼요.

■ 수행평가·지필고사 최종 점수
• 받은 점수와 반영비율만 넣으면 최종 원점수와 A~E 성취도가 바로 나와요
• 반영비율 합계가 100%인지 자동으로 확인해요
• "A까지 5.4점 남았어요"처럼 다음 등급까지 남은 점수를 알려 줘요

■ 남은 시험 목표 점수
• 지금까지 본 평가 점수로 기말고사에서 몇 점 받아야 목표를 이루는지 계산해요
• 등급별(A~D) 필요 점수를 표로 한눈에, '만약에' 슬라이더로 미리 보기

■ 내신 석차등급 (5등급제·9등급제)
• 수강자 수와 석차, 동점자 수만 넣으면 석차백분율과 등급을 계산해요
• 단위수를 반영한 평균 등급까지

■ 대학 학점(GPA)
• 4.5·4.3·4.0 만점 평점평균, P/F 과목 처리
• 다른 만점 기준으로 GPA 환산

■ 오늘의 급식·시간표
• 학교 이름만 검색하면 오늘 급식(조식·중식·석식)과 우리 반 시간표를 보여 줘요
• 급식 알림을 켜면 매일 점심 메뉴를 알려 드려요

■ AI 도우미
• "200명 중 15등이면 몇 등급?", "기말에서 몇 점 받아야 A야?"처럼 물어보면 바로 답해요
• 계산은 즉시, 그 밖의 궁금한 점은 사이트 자료를 근거로 AI가 답해요
• 이상한 답은 답 아래 '답변 신고'로 알려 주세요

■ 이런 분께 좋아요
• 수행평가 점수가 나오고 최종 점수가 궁금한 중·고등학생
• 기말고사 목표 점수를 정하고 싶은 학생
• 내신 등급을 미리 따져 보는 고등학생과 학부모
• 학점 평균을 계산하는 대학생

■ 안내
• 계산 결과는 참고용이에요. 실제 성적은 학교·대학의 평가 규정을 따라요.
• 웹사이트 naver1.cloud와 같은 서비스예요. 앱은 홈 화면에서 바로 열리고 급식 알림을 받을 수 있어요.
• 문의·오류 제보: 앱 안 '문의하기'
• 개인정보처리방침: https://naver1.cloud/privacy/
```

같은 낱말을 일부러 반복해서 채우는 건 정책 위반(키워드 스팸)이라, 기능 설명 안에 자연스럽게 한 번씩만 넣었다.

## 그래픽

| 칸 | 파일 | 규격 |
|---|---|---|
| 앱 아이콘 | `graphics/icon-512.png` | 512×512, 32비트 PNG(알파 포함) |
| 그래픽 이미지 | `graphics/feature-graphic.png` | 1024×500 PNG(알파 없음) |
| 휴대전화 스크린샷 | `graphics/phone-1.png` ~ `phone-6.png` | 1080×1920(9:16) PNG, 이 순서대로 |

스크린샷 문구(첫 3장이 설치 결정에 가장 중요):

1. 점수만 넣으면 / 최종 점수가 바로 (수행·지필 입력 + 하단 바 결과)
2. A까지 몇 점 남았는지 / 한눈에 (결과 카드)
3. 남은 시험에서 / 몇 점 받아야 할까? (목표점수)
4. 9등급제·5등급제 / 내신 등급 자동 계산
5. 우리 학교 급식·시간표 / 알림까지 한 번에
6. 모르는 건 / AI 도우미에게

원본은 `graphics/src/`. 화면을 바꾸면 실제 앱 화면을 다시 찍어 `src/raw/`를 바꾸고, `screenshot.html`·`feature.html`을 1080×1920·1024×500으로 찍는다.
