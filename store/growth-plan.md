# 사용자 유입 계획 (무료 위주)

## 목표

| 지표 | 출시 4주 목표 | 보는 곳 |
|---|---|---|
| 설치 수 | 500 | Play Console > 통계 |
| 스토어 방문 → 설치 전환율 | 30% 이상 | Play Console > 사용자 획득 > 스토어 등록정보 |
| 평점 | 4.5 이상, 리뷰 20개 | Play Console > 평점 및 리뷰 |
| 앱에서 들어온 방문 | 전체 방문의 10% | 사이트 관리자 대시보드(유입: `android-app://io.github.ritual1127.seongjeok`) |

## 1. 스토어 최적화 (ASO)

- 이름·간단한 설명·자세한 설명에 사람들이 실제로 검색하는 말을 넣었다(`listing-ko.md`).
- 스크린샷 첫 3장이 설치를 가른다: "점수만 넣으면 최종 점수가 바로" → "A까지 몇 점 남았는지" → "남은 시험에서 몇 점".
- 리뷰가 순위와 전환율을 크게 바꾼다. 테스터·친구에게 출시 첫 주에 솔직한 리뷰를 부탁한다(별점 조작 부탁은 정책 위반).
- 리뷰에는 48시간 안에 답한다. 불만 리뷰는 고친 뒤 "고쳤어요"로 답하면 별점을 다시 올려 주는 경우가 많다.

## 2. 웹사이트 → 앱 (가장 큰 유입원)

이미 매일 오는 사이트 방문자가 가장 쉬운 설치 대상이다.

- **앱 안내 카드**: 안드로이드 브라우저로 들어온 사람에게만 페이지 끝에 'Google Play에서 설치' 카드를 띄운다. 앱 안에서는 안 뜨고, 닫으면 다시 안 뜬다.
  - 켜는 법: `site-nav.js`의 `const PLAY_ID = '';`에 `io.github.ritual1127.seongjeok`를 넣고 배포
- 푸터 링크 '안드로이드 앱'을 추가하고, 사용법 안내에 '앱으로 쓰기' 단계를 넣는다.
- AI 도우미 지식(`scripts/kb/01-site.txt`)의 '홈 화면에 설치' 답에 플레이 스토어 링크를 더한다(`npm run build:kb` → 배포 → /admin '지금 색인하기').

## 3. 채널별 계획

| 채널 | 무엇을 | 언제 | 링크 |
|---|---|---|---|
| 카카오톡(반·동아리·학원 단톡) | "기말 몇 점 받아야 A인지 바로 나옴" + 링크 | 시험 2주 전 | `utm_source=kakao` |
| 인스타그램·스레드·틱톡·유튜브 쇼츠 | 15초 화면 녹화: 점수 넣기 → 결과 → "A까지 5.4점" | 시험 2~3주 전, 주 2회 | `utm_source=insta` 등 |
| 네이버 블로그·티스토리 | 계산법 글(사이트 계산 가이드 재활용) + 앱 링크 | 주 1회 | `utm_source=blog` |
| 고등학생 커뮤니티(오르비·수만휘 등) | 내신 등급·목표 점수 계산 팁 글, 규칙 지키며 링크 | 시험 기간 | `utm_source=community` |
| 대학생(에브리타임 등) | 학점·GPA 환산 | 성적 발표(6월 말, 12월 말) | `utm_source=everytime` |
| 학교 게시판 | QR 포스터(Bitly QR) | 학기 초, 시험 전 | `utm_source=poster` |

각 커뮤니티의 홍보 규칙을 먼저 읽는다. 같은 글을 여러 곳에 반복해서 올리면 스팸으로 막힌다.

## 4. 시험 기간 달력 (고등학교 기준, 학교마다 다름)

| 시기 | 무엇 | 홍보 시작 |
|---|---|---|
| 4월 하순~5월 초 | 1학기 중간고사 | 4월 중순 |
| 6월 하순~7월 초 | 1학기 기말고사 + 수행평가 마감 | 6월 중순 |
| 9월 하순~10월 중순 | 2학기 중간고사 | 9월 중순 |
| 11월 하순~12월 중순 | 2학기 기말고사 | 11월 중순 |
| 6월 말, 12월 말 | 대학 성적 발표 | 직전 주 |

**지금(10월 말) 기준 다음 대목은 2학기 기말고사다.** 11월 중순까지 출시하는 것을 목표로 잡았다(노션 일정 참고).

## 5. 측정 링크

플레이 스토어 링크에 `referrer`를 붙이면 Play Console '사용자 획득'에서 채널별 설치가 보인다.

```
https://play.google.com/store/apps/details?id=io.github.ritual1127.seongjeok&referrer=utm_source%3D채널%26utm_medium%3D형식%26utm_campaign%3Dlaunch
```

예:
- 카카오톡: `...&referrer=utm_source%3Dkakao%26utm_medium%3Dshare%26utm_campaign%3Dlaunch`
- 인스타 프로필 링크: `...&referrer=utm_source%3Dinsta%26utm_medium%3Dprofile%26utm_campaign%3Dlaunch`
- 사이트 카드: `utm_source=naver1.cloud&utm_medium=site&utm_campaign=promo` (코드에 이미 들어 있음)

짧은 링크와 QR이 필요하면 출시 후 Bitly로 채널마다 하나씩 만든다(클릭 수도 따로 보인다).

## 6. 출시 주간 체크

- [ ] 사이트 앱 안내 카드 켜기(`PLAY_ID`) + 푸터 링크
- [ ] 테스터·친구에게 리뷰 부탁
- [ ] 카톡·인스타에 출시 소식(UTM 링크)
- [ ] 블로그 글 1개("기말고사 목표 점수 계산하는 법 + 앱")
- [ ] 1주 뒤 Play Console 획득 보고서로 잘 된 채널 확인 → 다음 시험 기간에 그 채널에 집중

## 7. 나중에 (돈이 드는 것)

- 구글 앱 캠페인(유료 광고): 하루 몇천 원부터 가능하다. 무료 채널로 전환율을 확인한 뒤 시험 직전 1~2주만 써 보는 것을 추천한다.
