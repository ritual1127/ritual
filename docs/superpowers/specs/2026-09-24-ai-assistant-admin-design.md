## AI 도우미: 3단 하이브리드
1. **규칙(브라우저, 즉시)**: 급식·시간표(저장된 학교로 NEIS 실시간 조회), 석차→등급(9·5등급),
   상위 %→등급, 점수→성취도, 학점 변환, 인사·문의 연결. `calc-core.js` 함수를 그대로 쓴다.
2. **검색(하이브리드)**: 브라우저 BM25(글자 2-gram) → 알려진 질문과 거의 같으면(다이스 유사도 ≥ 0.6) 준비된 답을 즉시.
   아니면 상위 문서를 서버로 보내고, 키워드 결과가 약하면 서버가 의미 검색(bge-m3 + Vectorize)을 더해 RRF로 합친다.
3. **생성형 AI(Workers AI, 무료 플랜)**: `@cf/google/gemma-4-26b-a4b-it`(생각 모드 끔) 스트리밍, 실패하면
   `@cf/qwen/qwen3-30b-a3b-fp8`, 그것도 실패하면 관련 자료 카드 + 문의하기 안내. 측정: 첫 글자 0.2~0.5초, 답 1회 약 6뉴런
   (무료 1만 뉴런/일 ≈ 1,500회). 무료 플랜이라 한도를 넘어도 과금 없이 3단계 대체 답으로 넘어간다.

대화는 sessionStorage에 두어 페이지를 옮겨도 이어진다. 답의 링크는 사이트 내부 주소만 링크로 만든다.

- 화면: 기간(오늘·7일·30일·90일), 방문자·페이지뷰·계산 완료·AI 질문·새 문의 카드, 일별 추이, 인기 페이지, 도구별 계산,
