# 미니멀 도구 + 리퀴드 글래스 — 설계

## 배경

사용자는 지금 사이트가 "너무 AI스럽다"고 느끼고, 사람이 만든 완성도 있는 느낌을 원한다. 선택지 가운데 방향은 **미니멀 도구**, 리퀴드 글래스 범위는 **떠 있는 조작부만**, 배포는 **검증 후 바로 배포**를 골랐다.

AI스럽게 보이는 원인(진단):
- 모든 페이지가 같은 틀이다: 윗제목, 제목, 설명 한 줄, 카드마다 붙은 부제, 친절한 안내 문구.
- 모든 요소를 둥근 카드(18px)와 그림자로 감싸고 알약 칩을 반복한다.
- 점 격자 배경, 템플릿 기본값인 "→" 링크, 장식용 낙서가 있다.

## 원칙

- **포인트는 형광펜 하나.** 나머지는 잉크와 종이 두 가지 색으로만 쓴다. 등급 색 틴트, 파란 채움, 점 격자를 없앤다.
- **상자를 줄인다.** 카드 테두리와 그림자 대신 여백과 1px 가는 선으로 구분한다. 남는 둥근 모서리는 12px 이하로 한다.
- **글을 줄인다.** 윗제목, 설명 한 줄, 카드 부제, "계산 버튼은 없어요" 같은 UI 설명, "→" 화살표를 없앤다. 라벨은 명사로 짧게 쓴다.
- **글래스는 조작부에만.** 떠 있는 상단 캡슐, 도구 메뉴 팝오버, 미니 결과, 되돌리기 알림에만 쓴다. 내용은 종이 그대로 둔다(애플 Liquid Glass 원칙).
- 기능, URL, SEO 메타, 저장 키, 롤링과 축하 모션은 유지한다. 제목 낙서와 카드 등장 애니메이션은 장식이므로 없앤다.

## 상단: 리퀴드 글래스 캡슐

- 화면 위에 떠 있는 캡슐 하나로 만든다. 상단 여백 10px, 좌우 12px, 모서리 20px, 높이 56px, sticky.
- 글래스 표현:
  - 반투명 종이색(surface 60%)
  - `backdrop-filter: blur(18px) saturate(1.8)`
  - 1px 흰 반투명 테두리
  - 위쪽 안쪽에 빛 반사 하이라이트(inset)와 비스듬한 윤광(`::before` radial-gradient)
  - 부드러운 그림자
  - 다크 모드용 값은 따로 둔다.
- **모바일**: `[A+ 마크] [현재 도구명 ▾] … [미니 결과] [☾]`. 도구명 버튼을 누르면 7개 도구 목록이 글래스 팝오버로 열린다(`aria-expanded`, Esc·바깥 클릭·링크 이동 시 닫힘). 워드마크는 화면에서 숨기고 스크린리더용으로만 남긴다.
- **데스크톱(960px 이상)**: `[A+ 성적계산기] [수행·지필 목표점수 내신등급 학점 GPA 환산 | 급식 시간표] [☾]`. 도구 탭이 캡슐 안에 한 줄로 보이고, 현재 탭에는 형광펜 밑줄을 긋는다.
- 도구 링크 7개는 두 크기 모두 같은 `<nav>` 안에 DOM으로 있다(SEO 유지). 푸터에도 도구 링크를 텍스트로 둔다.
- 기존의 별도 칩 줄(`.toolnav`)은 없앤다.

## 본문

- 배경은 종이색 단색이다(점 격자 제거).
- **페이지 제목**: h1 하나만 둔다(22px, 굵게). 윗제목과 설명 줄은 삭제한다.
- **결과 영역**(카드 테두리·그림자 없음)
  - 라벨 줄: `최종점수 ··· 초기화`(텍스트 버튼)
  - 큰 숫자와 형광펜 밑줄, 등급 글자(잉크 테두리 사각형, 색 틴트 없음)
  - 0~100 진행선: 2px 잉크선에 눈금만 두고 A~E 글자는 ink-3
  - 메타 한 줄
- **입력 영역**: 섹션 라벨(작은 굵은 글씨)과 스테퍼, 가는 선으로 나뉜 행. 입력칸은 투명 배경에 밑줄만 두고, 포커스하면 형광펜 연한 배경.
- **비율 빠른 선택, 등급제·만점 기준**: 알약 칩이나 세그먼트 대신 가는 선 세그먼트(텍스트)로 바꾸고, 선택된 항목에 형광펜을 칠한다.
- **데스크톱 2단**: 결과는 오른쪽에 sticky, 왼쪽 입력과는 1px 세로선으로 구분한다.
- **설명(SEO) 섹션**: 상자 없이 작은 글씨로, 위에 가는 선 하나. 내용은 유지한다.
- **표**: 등급 칩 대신 텍스트로 쓰고, 강조할 행에만 형광펜 연한 배경을 둔다.
- **글·FAQ·사용법·개인정보·가이드 허브**: 카드 없이 본문만 둔다(최대 680px). 가이드 허브 카드는 가는 선으로 나뉜 목록이 된다. 리드 박스와 공식 박스는 왼쪽 가는 선만 남긴다.
- **급식·시간표**: 카드 없이 가는 선 구분. 학교 정보는 한 줄 텍스트와 텍스트 버튼.
- **푸터**: 한 줄 안내(저장 위치 포함)와 링크, 저작권.

## 모션

- 유지: 숫자 롤링, 등급 도장(단색 배지), 달성 축하(종이 조각과 도장 스티커), 새 행 등장, 되돌리기 알림.
- 삭제: 제목 펜 낙서, 카드가 종이처럼 등장하는 효과.
- 글래스 팝오버: 180ms 동안 흐림과 투명도를 바꾸며 열린다. `reduced-motion`이면 즉시 열린다.

## 테스트와 검증

- `npm test`, SEO 100/100.
- 기존 QA 스위트 170개를 새 마크업에 맞게 고쳐서 통과시킨다. 칩과 도구 칩 선택자가 바뀐다.
- 새로 확인할 것:
  - 모바일 도구 메뉴 열기·닫기(Esc, 바깥 클릭)와 `aria-expanded`
  - 데스크톱 탭 표시
  - 글래스에 `backdrop-filter`가 실제로 적용되는지
  - 360·390·1440 라이트·다크 스크린샷
  - 가로 스크롤 없음, 콘솔 오류 0
- 배포: main을 push하고 Pages 빌드가 끝나면 라이브 스모크 테스트를 한다.
