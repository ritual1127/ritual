## 화면과 동작

### 1. `/suneung/` 수능 최저 계산기
기존 도구 페이지 골격을 그대로 쓴다: `body[data-app="suneung"]`, `.page-head`(제목 + 초기화), `.calc`(입력 묶음 + 결과 카드), `.note`(본문).
- 제목: **수능 최저 계산기**(다른 도구처럼 22px/30px 차분한 제목).
- 제목 아래 D-day 줄(시즌 줄과 같은 `.season` 모양, 링크 아님):
  - 수능 전: `D-14` 2027학년도 수능 · 11월 19일(목)
  - 수능 당일: `오늘` 지금 2교시 수학 · 12:10 종료 (시간표 기준. 시험 전엔 "08:10까지 입실", 끝나면 "시험 끝 · 수고했어요")
  - 수능 다음 날~통지 전날: `D-n` 성적 통지 · 12월 11일(금)
  - 통지 뒤: 다음 학년도 수능(2028학년도, 2027-11-18) D-day. 표에 다음 수능이 없으면 줄을 숨긴다.
  - 정적 HTML에는 "2027학년도 수능 2026년 11월 19일(목) · 성적 통지 12월 11일(금)"이 들어 있다(검색·JS 없음 대비).
- 카드 1 **영역별 등급**: 국어, 수학, 영어, 한국사, 탐구 1, 탐구 2. 각 줄 = 영역 이름 + 등급 고르기(`select.input`, 빈 값 + 1~9등급).
  영어·한국사 줄에는 **원점수** 칸(영어 0~100, 한국사 0~50)이 더 있고, 넣으면 등급 칸이 자동으로 바뀐다. 등급을 직접 고르면 원점수 칸은 비운다
  (성적표에는 원점수가 없으므로 등급만 넣는 경우도 지원). 국어·수학·탐구는 원점수 칸 없이 등급만 고른다(등급컷은 시험 후 입시기관이 낸다).
- 카드 2 **최저 조건**:
  - 반영 영역: 국어·수학·영어·탐구 토글(기본 모두 켬, 최소 1개).
  - 기준: `[3]개 영역 [등급 합 | 각각] [6] 이내` — 개수 1~(켠 영역 수), 합이면 한도 개수~개수×9, 각각이면 1~9등급.
  - 탐구: 상위 1과목(기본) / 2과목 평균 / 2과목 평균(소수점 버림).
  - 필수 영역: 없음(기본) / 켠 영역 중 하나("수학 포함" 같은 조건).
  - 한국사: 조건 없음(기본) / 1~9등급 이내.
- 결과 카드: 라벨 "최저 충족 여부".
  - 빈 상태: — / "등급을 고르면 바로 확인돼요."
  - 입력 부족: "3개 영역 등급이 필요해요(지금 2개)" / 필수 영역·탐구 2과목·한국사 등급이 빠졌으면 그 이름을 말한다.
  - 합 조건: 큰 숫자 = 고른 영역 등급 합(소수 가능), 단위 "합", 상태 알약 **충족**(초록)/**미충족**(빨강, 상태 색만 사용).
    풀이: "국어 2 + 영어 2 + 탐구 1 = 5 · 최저 6 이내". 미충족이면 "합을 2 더 낮춰야 해요".
  - 각각 조건: 큰 숫자 = 한도 안에 든 영역 수, 단위 "개", 풀이: "2등급 이내 2개 · 3개 필요".
  - 한국사 조건 미달이면 합·각각과 상관없이 미충족, 메타 줄에 "한국사 5등급 · 4등급 이내 필요".
  - 충족으로 바뀌면 다른 도구처럼 도장 스티커 "최저 충족" + 축하(`achievement`). 휴대폰 하단 바 미니 결과: `합 5 · 충족`.
- 선택은 이 기기에만 저장(localStorage `suneungCalc`), 초기화는 되돌리기 알림 포함(다른 도구와 같음).
- 본문(`.note`, 정적 HTML): 최저 계산법과 예시 3개(3합 6, 탐구 평균 버림, 필수 영역), 영어·한국사 등급표, 2027 시간표 표
  (시험 당일엔 지금 교시 줄 강조), 주요 일정, 자주 묻는 질문 4~5개, 가이드 글 링크. 표는 휴대폰 폭에 맞춘다(좌우 스크롤 없음).

## 계산 규칙(순수 함수, `calc-core.js`, Node 점검 `scripts/test-calc.mjs`)
- `absGrade(subject, score)`: subject `english|history`, 범위 밖·숫자 아님이면 null.
- `suneungMinimum(grades, rule)`:
  - grades: `{ kor, math, eng, hist, inq1, inq2 }` 각 1~9 또는 null.
  - rule: `{ areas: ['kor','math','eng','inq'], count, mode: 'sum'|'each', limit, inq: 'best'|'avg'|'avgFloor', must: ''|area, hist: 0|1~9 }`.
  - 탐구 값: best = 입력된 것 중 좋은 등급, avg = 두 과목 평균(둘 다 있어야 함), avgFloor = 평균 소수점 버림.
  - 후보 = 켠 영역 중 값이 있는 것. 필수 영역이 켜져 있으면 먼저 넣고 나머지는 좋은 등급 순으로 채운다.
  - 결과: `{ status: 'pending'|'met'|'unmet'|'invalid', missing, picked: [{ area, grade }], sum, within, gap, histOk }`.
    pending이면 무엇이 빠졌는지(`missing`: 필요한 개수, 필수 영역, 탐구 2과목, 한국사) 알려 준다.
  - 부동소수 오차는 기존 `roundFloat`로 정리. 개수 > 켠 영역 수면 invalid.
