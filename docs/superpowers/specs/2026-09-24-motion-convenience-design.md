# 모션 & 편의 기능 추가 — 설계

## 배경

2026-09-23에 "노트 & 형광펜" 리디자인이 끝났다. 사용자는 두 가지를 추가로 요청했다. 하나는 **더 재밌고 신기한 애니메이션**, 다른 하나는 **더 편한 사용**이다. 선택지 중 아래를 골랐고, 진행은 "끝까지 자동"이다.

- 애니메이션: 숫자 롤링 + 등급 도장, 달성 축하 효과, 손글씨 낙서 효과(화면 전환 효과는 고르지 않음)
- 편의: 만약에 슬라이더, 비율 빠른 채우기, 되돌리기 알림(결과 공유는 고르지 않음)
- 추가 요청: "초기화 버튼 넣어줘". 지금 버튼은 입력칸 맨 아래에 있어 잘 보이지 않는다. 모든 계산기의 결과 카드 오른쪽 위로 옮기고, 버튼이 없던 GPA 환산에도 넣는다.

## 원칙

- "노트 & 형광펜" 톤을 유지한다. 모션은 **종이, 잉크, 도장, 형광펜**이라는 소재에서만 가져온다.
- 새 라이브러리는 쓰지 않는다. CSS 애니메이션과 Web Animations API로 만든다.
- `prefers-reduced-motion: reduce`이면 모든 움직임, 종이 조각, 진동을 끈다. 결과는 즉시 표시한다.
- 움직임은 결과가 바뀌는 순간과 성취를 확인하는 데만 쓴다. 계산 속도, 레이아웃 흔들림(CLS), LCP를 나빠지게 하면 안 된다.
- 축하는 사용자가 입력해서 **상태가 바뀌는 순간에만** 한다. 저장된 값으로 다시 열었을 때는 도장만 조용히 보여준다.

## 애니메이션

### 1. 숫자 롤링 (결과 숫자 5곳)

- 결과 숫자를 슬롯머신처럼 굴린다. 숫자 한 자리마다 0~9 세로 띠가 있고, 목표 숫자로 굴러간다. 전환은 0.6s에 끝에서 살짝 튕기며, 자리마다 40ms씩 시차를 둔다.
- 처음 나타날 때나 자릿수 모양이 바뀔 때(예: `9.5`→`10`)는 띠를 새로 만들고 0에서 굴러 들어온다.
- 구조: 보이지 않는 원문(너비와 기준선 담당), 그 위에 겹친 롤 레이어(`aria-hidden`), 스크린리더용 `sr-only` 텍스트. 요소에는 `data-value`로 현재 값을 남긴다(테스트도 이 값을 읽음).
- 공용 함수: `rollNumber(el, text)`(site-nav.js). 적용 대상: 수행·지필 `#finalValue`, 목표 `#requiredValue`, 내신 `#avgValue`, 학점 `#gpaValue`, 환산 `#convertedValue`.

### 2. 등급 도장

- 수행·지필의 등급 배지는 등급 글자가 바뀔 때마다 도장처럼 찍힌다. 크게 기울어진 채 들어와 살짝 눌렸다가 -4° 기울기로 멈추고, 잉크 테가 한 번 퍼진다. 배지는 평소에도 -4° 기울어져 있다.
- 공용 함수: `stampIn(el)`.

### 3. 달성 축하

- 조건에 들어가는 순간 두 가지를 한다.
  1. 결과 카드에서 **형광펜 색 종이 조각 26개**가 위로 터졌다가 떨어진다(1.1~1.5s).
  2. 안드로이드에서 `navigator.vibrate(18)`로 한 번 진동한다.
- 결과 카드 오른쪽에 **빨간 인주 도장 스티커**가 찍힌다. 조건을 벗어나면 사라진다.

| 페이지 | 조건 | 스티커 문구 |
|---|---|---|
| 수행·지필 | 최종 등급 A | 참 잘했어요 |
| 목표점수 | 이미 목표 달성(`reached`) | 목표 달성 |
| 내신등급 | 평균 등급이 반올림하면 1(1.5 미만) | 1등급 |
| 학점 | 만점 대비 90% 이상 | 참 잘했어요 |

- 공용 함수: `celebrate(card)`(종이 조각 + 진동)와 `setSticker(card, text, animate)`(빈 문자열이면 숨김).

### 4. 손글씨 낙서

- 페이지 제목(`.page-head h1`, `.prose h1`) 아래에 펜으로 그은 듯한 물결 밑줄 SVG가 로드 때 0.9s 동안 그려진다(`stroke-dashoffset`). 색은 잉크 파랑.
- 카드는 종이를 한 장씩 내려놓듯 차례로 들어온다. 결과 카드, 입력 카드, 설명, 가이드 카드가 대상이다. 이동은 14px, -0.6°에서 0, 0.45s, 카드마다 60ms 시차. **제목(LCP)은 움직이지 않는다.**
- 새로 추가된 행(스테퍼 +, 평가·과목 추가, 되돌리기로 복원된 행)만 스르륵 나타난다. 다시 그려지는 기존 행은 움직이지 않는다.

## 편의 기능

### 5. 초기화 버튼과 되돌리기 알림

- 모든 계산기(5개) 결과 카드의 머리줄 오른쪽에 `↺ 초기화` 버튼을 둔다. 입력칸 아래 초기화 버튼은 없애고 "이 기기에만 저장돼요" 안내만 남긴다.
- 초기화는 **한 번 누르면 바로 실행**하고 `입력을 초기화했어요 · 되돌리기` 알림을 5초 동안 띄운다. 되돌리기를 누르면 직전 상태 그대로 돌아온다. 두 번 누르기(`armReset`)는 없앤다.
- 행 삭제(목표·내신·학점)와 수행·지필 개수 줄이기에도 같은 알림을 쓴다. 값이 있는 행을 지웠을 때만 띄우고, 되돌리면 원래 위치로 복원한다.
- 알림은 화면 위쪽 가운데, 상단바 바로 아래에 뜬다. 모바일 하단 앵커 광고와 겹치지 않게 하기 위해서다. `role="status"`이고 한 번에 하나만 뜬다. 공용 함수: `showToast(message, { action, onAction })`.

### 6. 비율 빠른 채우기

- 수행·지필 입력 영역 맨 위에 "반영비율 빠른 선택" 칩을 둔다: `수행 20 · 지필 80`, `30 · 70`, `40 · 60`, `50 · 50`. 누르면 그룹 비율을 행 수로 나눠 채운다. 소수 둘째 자리까지 쓰고, 합이 정확히 맞도록 나머지는 마지막 행에 준다(예: 40을 3개로 나누면 13.33, 13.33, 13.34). 행이 0개인 그룹은 1개를 만든다. 지금 비율과 같은 칩은 `aria-pressed`로 표시한다.
- **남은 % 채우기**
  - 수행·지필: 비율 칸 중 하나만 비었고 나머지 합이 100 미만이면, 비율 카드에 `빈 칸에 남은 N% 넣기` 버튼이 나온다.
  - 목표점수: 합이 100이 아니고 `100 − 본 평가 비율 합`이 0보다 크고 100 이하이면 `남은 시험 비율을 N%로 맞추기` 버튼이 나온다.
- 순수 함수: `splitWeights(total, count)` → 합이 정확히 `total`인 배열(calc-core.js).

### 7. 만약에 슬라이더 (목표점수)

- 결과 카드 안에 "{시험명}에서 [ N ]점 받으면 → 최종 X점 · 등급" 슬라이더(0~100, 1점 단위)를 둔다. 끄는 동안 최종 점수와 등급이 실시간으로 바뀐다.
- 슬라이더 아래에 A·B·C·D 경계가 되는 시험 점수 위치를 눈금 라벨로 표시한다. 0~100 범위 안인 것만 보인다.
- 초깃값은 필요 점수를 올림한 값(0~100으로 제한)이다. 사용자가 한 번 움직이면 그 값을 유지한다.
- 계산 결과가 없거나 남은 비율이 0%이면 숨긴다. `aria-valuetext`는 "기말고사 88점, 최종 86.2점 B등급".
- 순수 함수: `projectedScore(completed, remainingWeight, examScore)`(calc-core.js).

## 파일

- `calc-core.js`: `splitWeights`, `projectedScore` 추가. `scripts/test-calc.mjs`에 테스트 추가.
- `site-nav.js`: `rollNumber`, `stampIn`, `celebrate`, `setSticker`, `showToast` 추가, 제목 낙서 주입, `armReset` 제거.
- `styles.css`: 롤, 도장, 스티커, 종이 조각, 알림, 낙서, 카드·행 등장, 슬라이더, 칩 스타일과 `reduced-motion` 처리.
- 계산기 5개 페이지: 결과 카드 머리줄 초기화 버튼, 롤링과 축하 연결, 각 편의 기능.

## 테스트와 검증

- `npm test`(메타 + calc-core)와 SEO 100/100을 유지한다.
- headless Chrome QA에서 확인할 것:
  - 롤링 값(`data-value`)과 sr 텍스트가 맞는지
  - A 달성 시 종이 조각 생성과 스티커 표시, 재방문 시 스티커만 보이고 조각은 없는지
  - 초기화 → 되돌리기로 원상복구
  - 행 삭제 → 되돌리기로 같은 위치에 복원
  - 프리셋 40:60을 3+2행에 적용하면 13.33/13.33/13.34/30/30
  - 남은 % 채우기
  - 슬라이더를 움직이면 최종 점수와 등급 반영
  - `reduced-motion`에서 종이 조각 0개
  - 기존 QA 스위트가 새 초기화 흐름과 `data-value` 기준으로도 통과하는지
  - 콘솔 오류 0
